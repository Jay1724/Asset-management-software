Mining Asset Management Platform

White-label, multi-tenant asset management purpose-built for mining operations — automated depreciation on real usage data, resource allocation, expiry/compliance tracking, and an immutable audit trail, replacing spreadsheet-based tracking.

View on GitHub Read the docs

Why it's different

Depreciation

Units-of-production, tied to real usage

Straight-line, declining-balance, and units-of-production depreciation — the last one priced per hour or per tonne, ready to be driven by a telematics feed instead of a calendar.

Security

Tenant isolation enforced by Postgres

Row-Level Security policies key every tenant-scoped table on the current request's tenant — a bug in application filtering can't leak another tenant's data.

Branding

White-label per tenant

Logo, colors, and font resolved from the request's subdomain and injected as CSS variables at render time — consistent across the app and, eventually, exported reports.

Audit

Immutable valuation ledger

Every depreciation run and manual appreciation/adjustment is appended to a ValuationEvent ledger — never edited, never deleted.
